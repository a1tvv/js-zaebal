О проекте

Небольшой самостоятельный фронтенд о Формуле-1 — от гоночного контроля до истории чемпионата.

Задача

Показать, что многополосный сайт с интерактивным Live Timing можно собрать на обычных веб-технологиях. Статические страницы отображают материалы о сезоне, а live-раздел получает обновления с HTTP API.

Серверная часть на C++ остаётся отдельным компонентом и отвечает за выдачу JSON.

Главная фишка — гоночная таблица с позициями, погодой, состоянием трассы и схемой круга.

Технологии

  • Разметка HTML5
  • Стили CSS Grid + Flexbox
  • Интерактивность Vanilla JavaScript
  • Графики Chart.js CDN
  • Данные гонки Fetch API + JSON
  • Сервер C++ HTTP API

Запуск локально

Открой папку проекта в редакторе и запусти статический сервер (например, Live Server). Чтобы проверить обновление данных, подключи C++ API и укажи его адрес в Live Timing.

При открытии через file:// запросы fetch к локальному API могут блокироваться браузером.
