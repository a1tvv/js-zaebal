Что было сделано
================

В папке f1_dash добавлены две вещи:
1. Модальное окно «Связаться» на всех страницах сайта.
2. List и detail для пилотов: список из JSON и подробности в модальном окне.

Запуск
------
Сайт нужно открывать через локальный сервер (fetch не работает через file://).
Из папки f1_dash:

    python3 -m http.server 8000 --bind 127.0.0.1

Адрес: http://127.0.0.1:8000/frontend/index.html


1. Модальное окно «Связаться»
-----------------------------
Что видит пользователь: в правом верхнем углу шапки на каждой странице есть
кнопка «Связаться». По клику открывается окно с формой: имя и фамилия, группа,
email, телефон. Если поля заполнены неверно, под кнопкой «Отправить» появляется
сообщение об ошибке; если верно — сообщение об успехе. Данные никуда
не отправляются.

Закрытие окна: крестик, клавиша Esc, клик по тёмному фону.

Файлы:
- assets/js/modal.js — новый файл. Добавляет кнопку в шапку, создаёт окно
  (тег <dialog>) и проверяет форму регулярными выражениями (те же правила,
  что в about.js: имя, группа, email, телефон).
- assets/css/style.css — стили кнопки и окна (общий файл, подключён везде).
- frontend/*.html (все 10 страниц) — в конец <body> добавлена строка
  <script src="../assets/js/modal.js"></script>.

Примечание: регулярные выражения лежат и в about.js (форма на странице
«О проекте»), и в modal.js. При изменении правил менять нужно оба файла.


2. List и detail (страница «Пилоты»)
------------------------------------
JSON:
- assets/data/drivers.json — 12 пилотов. Поля: id, number, name, team,
  teamColor, country, birthDate, debut, titles, bio.

List:
- assets/js/drivers.js, функция list(items) — выводит карточки всех пилотов
  в сетку. Данные берутся из drivers.json через fetch.

Detail:
- assets/js/drivers.js, функция detail(id) — находит пилота по id и показывает
  его подробности в модальном окне: номер, команда, страна, дата рождения,
  дебют, титулы и короткая справка.
- Окно открывается по клику на карточку (или Enter с клавиатуры).
  Закрывается крестиком, Esc или кликом по фону.

Файлы:
- frontend/drivers.html — вместо 12 карточек вручную теперь пустой контейнер
  #driverList и <dialog id="driverModal"> для detail.
- assets/js/drivers.js — новый файл (fetch, list, detail).
- assets/css/drivers.css — стили кликабельных карточек и окна detail.
- assets/data/drivers.json — новый файл с данными.

Проверка: в браузере проверены загрузка всех 12 карточек, открытие detail
нужного пилота, три способа закрытия, открытие с клавиатуры и отображение
на ширине телефона. Ошибок в консоли нет.
