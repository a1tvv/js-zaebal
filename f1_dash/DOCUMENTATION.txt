F1 PADDOCK — ДОКУМЕНТАЦИЯ ПРОЕКТА
================================

О проекте
---------
F1 Paddock — учебный фронтенд о Формуле-1. Сайт объединяет страницы с
информацией о командах, пилотах, календаре и зачёте чемпионата, а также
разделы Live Timing, телеметрии, радио и истории F1.

Текущие страницы преимущественно статические и используют демонстрационные
данные. Live Timing может подключаться к HTTP API; если API недоступен,
страница по умолчанию переключается на демонстрационную гонку.

Технологии
----------
- HTML5
- CSS3 (в том числе Grid и Flexbox)
- Vanilla JavaScript
- Fetch API и JSON для получения данных Live Timing
- Chart.js через CDN для графиков телеметрии

Структура проекта
-----------------
frontend/              HTML-страницы сайта
assets/css/            Общие и постраничные стили
assets/js/             JavaScript-скрипты и пример обновления таблицы
backend/               Каталог для серверной части (в этой версии пуст)

Основные страницы в frontend/
-----------------------------
index.html       Главная страница
live.html        Live Timing: таблица пилотов, погода и карта трассы
teams.html       Команды чемпионата

Локальный запуск
----------------
Для корректной работы откройте проект через локальный HTTP-сервер, а не
напрямую через file://. Например, из корневой папки проекта выполните:

    python3 -m http.server 8000

Затем откройте в браузере:

    http://localhost:8000/frontend/

Также можно открыть корневую папку в VS Code и запустить статический сервер
расширением Live Server, открыв frontend/index.html.

Для загрузки Chart.js на странице телеметрии необходимо подключение к интернету.

Live Timing и подключение API
-----------------------------
Настройки находятся в блоке CFG внутри frontend/live.html:

    API: 'http://localhost:8080/api'
    POLL_MS: 2000
    MOCK_FALLBACK: true

Поменяйте API на адрес своего сервера. При включённом MOCK_FALLBACK сайт
покажет демо-гонку, если сервер недоступен или запросы завершаются ошибкой.
Для запросов с другого домена сервер API должен разрешать CORS для origin
сайта.

Live Timing использует следующие GET-эндпоинты:

GET /api/session
  Информация о сессии: name, flag, clock, lap, totalLaps, trackTime,
  weather. Поле weather может содержать wind, windDir, track, air,
  humidity, pressure и rain.

GET /api/standings
  Массив пилотов, отсортированный по позиции. Используемые поля:
  pos, driver, team, color, diff, lastLap, lastLapFlag, bestLap, gap,
  interval, status, tyres. Время кругов можно передавать в миллисекундах
  или строкой; интервалы — числом в секундах или строкой.

GET /api/track
  Координаты трассы в массивах x и y; sectors — индексы окончания первого
  и второго секторов. Пример: {"x":[...],"y":[...],"sectors":[120,260]}.

GET /api/positions
  Массив текущих координат машин с полями driver, x и y.

Дополнительный файл assets/js/live-example.js содержит отдельный пример
опроса /api/live и не подключён к странице frontend/live.html.

Данные и ограничения
--------------------
- Календарь, таблицы, радиосообщения и графики содержат демонстрационные
  материалы; перед публикацией сверяйте и обновляйте данные.
- Адрес API и данные гонки настраиваются отдельно от статических страниц.
- Каталог backend/ в текущем проекте не содержит реализации API.
- Информация о сезоне и участниках может быть демонстрационной и требует
  проверки по официальным источникам.
